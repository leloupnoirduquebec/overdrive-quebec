Quoi de neuf

  • Correctif (lier ton Discord) : « Copier le code » copie maintenant seulement le code. Avant, le lanceur copiait toute la commande « /lier code: … », et Discord pouvait répondre « cette commande est obsolète » quand on la collait.
  • Lier ton Discord, maintenant : 1. dans le lanceur, clique sur « Copier le code » ; 2. dans Le Bunker QC, salon 🎭rôles, clique sur le bouton « 🔗 Lier mon compte Overdrive » et colle le code. Tu peux encore taper /lier et coller le code dans la case.
  • Si Discord dit « commande obsolète » avec /lier : fais Ctrl+R dans Discord (ça recharge Discord), puis recommence, ou prends le bouton. Le lanceur te le rappelle sous ton code.
  • Correctif : dans le Logbook, la tuile « FREIN MOTEUR » s'appelle maintenant « FREIN MOTEUR ARMÉ ». Elle compte le temps où l'interrupteur du frein moteur est allumé en roulant, pas le temps où il freine vraiment (le jeu ne donne que l'interrupteur).
  • Correctif (Ronde de sécurité) : si « Mettre de côté » bloque sur un fichier après en avoir déplacé d'autres, le lanceur dit maintenant combien sont déjà mis de côté et refait la ronde tout de suite. Il ne déplace aussi que les fichiers qui sont encore de vieilles copies au moment du clic.
  • Correctif : le message des vieux mods du Workshop est bien écrit au singulier quand il n'y en a qu'un.

Windows affiche « Windows a protégé votre ordinateur »?

C'est SmartScreen. Il avertit pour tout programme qu'il n'a pas encore vu souvent, et ce lanceur est fait par des joueurs, pas par une entreprise qui paie un certificat. Clique sur Informations complémentaires, puis sur Exécuter quand même.

Avant de le faire, tu peux vérifier que le fichier est bien celui-ci : c'est l'étape suivante.

Comment vérifier le fichier

L'empreinte SHA-256 du fichier doit être exactement :

f1a156a3aa125981e2a3b078a6449eee2dc77f97694c17b7f725a563e37ff8f2

Pour la calculer : ouvre PowerShell dans le dossier du téléchargement et tape

Get-FileHash .\Overdrive.exe -Algorithm SHA256

Si les deux empreintes sont identiques, le fichier n'a pas été modifié en chemin. Ensuite, le lanceur se met à jour tout seul : chaque mise à jour est signée, et il refuse tout ce qui n'est pas signé par la clé de la communauté.
